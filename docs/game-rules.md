# Rules

## 百マス計算の報酬
- 今日初回: +10GP。
- 反復報酬: 正解率ポイント × スピードポイント。
- 正解率ポイント: 60%以下=0、61〜70%=1、71〜99%=2、100%=3。
- スピードポイント: 120秒以内=3、240秒以内=2、240秒超=1。

## 算数ギルド Ver1.0
- ギルドクエスト1〜5は各10問の四択。正解で次へ進み、不正解でそのクエストの1問目へ戻る。
- 再挑戦時も問題順は固定し、選択肢の位置だけを入れ替える。
- 各クエストは初回攻略のみ5GP。攻略後は再挑戦できない。
- 後続クエストは、前段階の問題を5問含めて学習内容を積み重ねる。
- ギルドテスト1はクエスト1〜5攻略後に解放。全問題群から20問をランダム出題する。
- 正解率90％以上で合格。合格5回で称号が「素人」から「見習い」になる。
- テスト報酬は正解率ポイント×スピードポイント。正解率90〜99％=1、100％=2。180秒以内=2、300秒以内=1、300秒超=0。


## 算数ギルド Ver2.0 追加ルール

- ギルドテスト1に5回合格すると「見習い」となり、ギルドクエスト6が解放される。
- ギルドクエスト6〜10も各10問。正解で次へ進み、不正解でそのクエストの1問目へ戻る。
- 各クエストは初回攻略時のみ5GPを受け取り、攻略後は再挑戦できない。
- ギルドクエスト6〜10をすべて攻略するとギルドテスト2が解放される。
- ギルドテスト2はクエスト6〜10の問題からランダム20問を出題し、何度でも挑戦できる。
- テストは正解率90%以上で合格。タイムと正解率の掛け算で、控えめなGPを受け取る。
- ギルドテスト2に5回合格すると称号「徒弟」が認定される。

## 社会ギルド Ver1.0「世界のすがた」

- 対応範囲はテキスト p.26〜28。
- ギルドクエスト1〜5は各10問。クエスト2以降は、前半5問が直前クエストの復習、後半5問が新しい内容。
- 正解で次へ進み、不正解でそのクエストの1問目へ戻る。
- 各クエストは初回攻略時のみ5GP。攻略後は再挑戦できない。
- クエスト1〜5をすべて攻略するとギルドテスト1が解放される。
- ギルドテスト1は、各クエストの新規学習範囲から4問ずつ、合計20問をランダム出題する。完全ランダムではなく、必ず全範囲を網羅する。
- ギルドテスト1は何度でも挑戦できる。正解率90％以上で合格し、合格かつ5分以内で2GP。
- 「ふりかえりの修行」の社会「世界のすがた」では、社会ギルドの問題群から5問をランダム出題する。

## 学びの森 Ver1.0「算数の広場」

- ギルドホールから「学びの森」へ移動し、算数ギルドマスターと自分のペースで学び直す。
- 最初の教材は、和差算「兄は弟より180円多く、2人の合計が1700円」。
- 会話は吹き出しをタップして一文ずつ進める。説明中は「ひとつ戻る」「最初から」を使用できる。
- 黒板上でテープ図を段階的に表示し、「違う180円を外す→同じ2本に分ける→多い方へ戻す」を視覚化する。
- 確認は選択式、ドラッグ操作、数字パッド式、手順並べ替え式を組み合わせる。
- 不正解で最初からやり直しにはせず、その場でヒントを出して考え直せる。
- 右側から開くメモパッドに、指またはApple Pencilで自由に筆算できる。描画内容は採点や文字認識には使わない。
- メモパッドは細い鉛筆1種類で、「ひとつ戻す」「全部消す」「閉じる」を備える。
- 学び直し完了はLocal Storageへ記録する。速度評価や時間制限は設けない。


## GPバランス調整 Ver1.0（2026-07-26）

- 百ます計算：従来どおり、1日初回10GP＋正答率ポイント＋スピードポイント。
- 学びの森：全26レッスンのどれかをその日最初に修了すると3GP。同日2回目以降は0GP。
- ふりかえりの修行：基本2GP／標準3GP／挑戦4GPを毎回獲得。
- ふりかえりの修行の難易度別デイリーボーナス：基本+1GP／標準+2GP／挑戦+3GP。教科・単元をまたいで各難易度1日1回。
- ふりかえりの修行では、正答率とタイムは学習記録として表示するが、GP計算には使わない。
- 社会「世界のすがた」は、旧標準を新基本、旧挑戦を新標準へ移行。新挑戦は塾プリント追加まで準備中。

## 今日のデイリー掲示板

ギルドホールには、当日まだ獲得していないデイリーGPを確認できる掲示板を置く。未達成項目のGOボタンから対象へ直接移動でき、達成すると獲得済み表示へ変わる。

ふりかえり修行の本日初回ボーナスは教科と難易度の組み合わせごとに独立する。算数の基本・標準・挑戦と、社会の基本・標準・挑戦は別々に獲得できる。

## フクロウ伝令

フクロウはギルド本部から重要な知らせがある時だけ部屋へ現れる。家具の配送、新しいギルドや機能、特別な達成などを知らせる。日常の励ましやデイリー催促には使用しない。
